    HTML, CSS & JavaScript

    The web platform is built on three complementary technologies. Each has a distinct job, and together they form every page you browse.

    HTML

    HTMLHTML gives a page its structure through headings, paragraphs, links, images, and forms.

    CSS

    CSSCSS controls layout, color, spacing, and typography so the same page can adapt to different screens.

    JavaScript

    JSJavaScript responds to actions and updates the page, like adding an Update row when you click the plus button.

    How they work together

    The browser reads the HTML to build the page, applies CSS to style it, and runs JavaScript to handle interactions.
